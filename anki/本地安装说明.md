### 安装其余插件

1. 在 Anki 中打开“工具 → 插件 → 获取插件”。
2. 输入上表对应的数字编号，按需下载安装；编号也对应 AnkiWeb 插件页面 `https://ankiweb.net/shared/info/编号`。
3. 安装后重启 Anki，并按需配置插件。上表仅记录当前安装清单，不保证 AnkiWeb 始终提供相同版本。
4. Hanzi Writer Card 与 HyperTTS 如需保留此次兼容修复，请使用本目录中的本地安装包；从 AnkiWeb 更新可能覆盖补丁。

## 安装步骤

1. 建议先备份 Anki 数据与原插件文件，关闭正在编辑的卡片窗口。
2. 打开 Anki，进入“工具 → 插件 → 从文件安装”。
3. 分别选择这两个 `.ankiaddon` 文件，不需要解压。
4. 完全退出 Anki，再重新打开。
5. 测试 Hanzi Writer Card 的“Add Audio”，以及 HyperTTS 的“Preview Audio”。

安装包沿用原插件数字编号，用于替换同编号插件，避免多装一份。
如果之前以 `hanzi_quiz` 或 `hypertts` 名称手动安装过副本，清单声明了冲突，
Anki 会停用对应别名副本。不要同时启用新旧副本。

## 配置与验证范围

- 未打包个人 `meta.json`、`user_files`、账号/API 密钥配置、生成音频、日志或 Python 缓存。
- 包含插件代码、所需依赖及静态资源；Hanzi Writer 包含词典和原许可证。
- HyperTTS 仅携带空白默认配置；在另一台电脑安装后，需要自行配置语音服务与预设。
- 同编号重装时，Anki 安装器会保留原插件元数据和 `user_files`；仍建议先备份。
- 本次修复通过了离线针对性测试；实际界面、联网语音服务和播放效果需安装重启后确认。
- 本地补丁可能被以后的官方插件更新覆盖。请保留安装包，需要时可以重新安装。
- 安装包不包含卡片、牌组、复习进度或 Anki 个人资料。
- `SHA256SUMS.txt` 可用于核对安装包是否发生变化。
